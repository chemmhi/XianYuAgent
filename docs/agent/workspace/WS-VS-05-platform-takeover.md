# WS-VS-05 Workspace 平台接管用户故事清单

## 验收口径

- Workspace 只编排现有领域服务，不复制商品、卡券、订单、账号或凭证数据模型。
- 每条故事必须带当前账号 `accountId`，服务端再次校验管理员 scope。
- 读取动作返回脱敏的领域摘要；写动作遵循 Policy、Confirmation、Idempotency、Outbox、Audit 与已有 Run/Step 状态机。
- 同一业务幂等键重复执行只返回原结果；外部结果未知时先查询状态，不盲目重放。
- 验收证据包含：单元测试、MemoryStore HTTP smoke、真实 PostgreSQL / 平台适配器集成测试，以及 Workspace 浏览器 E2E。

## 用户故事

### 账号与上下文

- **WS-AC-01 查看账号与健康度**：管理员说“列出账号和连接状态”，Workspace 返回账号、登录态、IM、自动回复、自动发货和凭证健康摘要；不返回 Cookie/Token 明文。
- **WS-AC-02 切换账号上下文**：管理员在会话中指定账号，Workspace 校验 scope 后切换当前会话上下文；后续 Run 只能访问该账号数据。
- **WS-AC-03 刷新连接状态**：管理员说“检查账号连接”，Workspace 调用账号连接验证，持久化账号健康变化和审计记录。
- **WS-AC-04 登录态恢复入口**：账号失效时，Workspace 返回重新授权/二维码登录入口和失败原因，不自动重放外部写动作。

### 运营分析

- **WS-OP-01 经营概览**：管理员说“分析今天/近 7 天经营情况”，Workspace 调用 DashboardService 返回销售、订单、自动处理率、待人工数、趋势和风险待办。
- **WS-OP-02 运营建议**：Workspace 基于真实 Dashboard、订单、商品、卡券和 Agent 摘要生成可执行建议；空数据时明确说明“暂无数据”，不得编造指标。
- **WS-OP-03 风险队列**：管理员询问“有哪些需要处理的异常”，Workspace 汇总失效账号、发货失败、交付配置缺失和未读会话，并附业务跳转引用。

### 商品

- **WS-PR-01 查询商品**：管理员按账号、标题、状态或商品 ID 查询商品列表/详情。
- **WS-PR-02 同步闲鱼商品**：管理员说“刷新/同步商品”，Workspace 调用 ProductSyncService，返回同步批次、拉取数量、创建/更新/跳过数量和账号失效原因。
- **WS-PR-03 编辑商品**：管理员修改标题、描述、价格、分类、回复模板或商品知识库；使用版本号并记录审计。
- **WS-PR-04 读取/生成知识库**：管理员查看、从会话生成或优化知识库；只使用已脱敏的人工回复与买家问题。
- **WS-PR-05 查看/更新自动化规则**：管理员读取或修改自动发货、未付款改价、发送赠品、求评价规则；启用规则时校验卡券绑定和账号 scope。
- **WS-PR-06 发布商品**：管理员要求发布单件/批量商品时生成发布预览和 Confirmation Card，确认后进入 Outbox/发布服务并跟踪结果。

### 卡券

- **WS-CO-01 查询批次与详情**：管理员按账号、状态、类型查询卡券批次，详情可受控查看正文和交付配置。
- **WS-CO-02 新建/导入卡券**：Workspace 解析批次名称、类型、内容和导入项，确认后创建批次并写入受控卡券域。
- **WS-CO-03 编辑卡券批次**：管理员修改名称、类型、交付配置或备注，使用版本校验并审计。
- **WS-CO-04 启用/禁用卡券**：管理员切换批次 `active/paused` 状态；启用前校验内容和账号归属。
- **WS-CO-05 删除/作废卡券**：删除只做软删除/作废，保留交付历史，不允许恢复后无审计启用。
- **WS-CO-06 复制卡券批次**：管理员复制批次配置和受控内容，生成新的批次与审计引用，不复用旧批次幂等键。
- **WS-CO-07 关联/解除关联商品**：管理员绑定或解绑商品，校验商品与卡券属于同一账号。

### 订单

- **WS-OR-01 查询订单**：管理员按账号、状态、商品、买家和时间查询订单及交付失败原因。
- **WS-OR-02 同步闲鱼订单**：管理员说“同步订单”，Workspace 调用 OrderService.refresh，返回同步批次、创建/更新/删除数量和自动化触发结果。
- **WS-OR-03 订单详情与交付预览**：管理员查看订单详情、商品上下文、卡券交付配置和失败原因；交付正文走受控 purpose 接口。
- **WS-OR-04 发货/重试/取消**：发货、重试和取消遵循支付、绑定、版本、幂等和人工确认策略；未知外部结果先查状态。

### Agent 运行与配置

- **WS-AG-01 运营动态摘要**：管理员询问 Agent 运行情况，Workspace 返回入站、处理中、完成率、转人工、失败、吞吐、P95 和健康组件。
- **WS-AG-02 运行列表**：管理员按时间、状态、阶段、决策和关键词查询 Agent Run。
- **WS-AG-03 运行详情/工作流**：管理员查看单次 Run 的阶段、事件、工具摘要、失败原因和修复审查状态；不暴露原始 prompt、凭证或买家敏感正文。
- **WS-AG-04 自动回复配置**：管理员读取或修改启用状态、循环/工具上限、超时、历史条数、回复长度、发送模式等；修改需 Confirmation 和版本校验。
- **WS-AG-05 OpenAI-compatible 模型配置**：管理员查看当前账号模型 Provider、Base URL、模型、Wire API、连通性和 API Key hint；新增/编辑/测试/启停走既有 OpenAISettingsService 与凭证服务，绝不回显密钥。
- **WS-AG-06 模型列表与连通性测试**：管理员要求测试 Provider 或查看模型列表，Workspace 返回模型元数据、耗时和可重试错误。

## 统一验收矩阵

| 维度 | 通过条件 |
| --- | --- |
| 真实领域调用 | 每条故事至少命中一个现有 Service/Store 路径，禁止只返回静态文本 |
| 账号隔离 | 跨账号读取/写入均返回 `FORBIDDEN`，且不产生外部调用 |
| 高风险写入 | 生成 Confirmation，确认后才进入 Outbox 或本地领域写入 |
| 幂等与状态机 | 重复确认返回原结果；Run/Step/Outbox 状态只按既有转移表变化 |
| 敏感数据 | Workspace 消息、事件和 ViewModel 不包含凭证、卡券正文、原始 Pi payload 或买家敏感内容 |
| 失败可恢复 | 账号失效、外部超时、版本冲突、结果未知均保留错误码、审计和可重试入口 |
| 证据 | 单元、HTTP smoke、PostgreSQL/平台适配器集成和浏览器 E2E 均可复现 |
