## 5. 人工复核完成条件

仅当以下条件全部满足，才可以把阶段 0 更新为 PASS 并进入阶段 1：

1. MR-001 至 MR-004 有明确结论，且 S0-R1、S0-R2、S0-R3 全部 PASS；
2. S0-I001 至 S0-I004 已关闭，或被明确转化为有负责人、截止阶段和书面接受的风险；
3. 阶段状态 FAIL / BLOCKED 的分类争议已在 STATUS.md 记录唯一裁决；
4. 产品 / 设计、安全 / 运维、架构 / 后端责任人确认其对应决策项；
5. 评审问题修复后重新执行受影响门禁，且没有新的回归。

在完成上述复核前，不得进入阶段 1，不得开始真实业务后端、数据库迁移或前后端联调。
