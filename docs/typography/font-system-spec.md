# 全平台字体规范（v0.1 评审稿）

> 目标：解决平台中“字体太小、阅读疲劳、层级不统一”的问题。本文先作为评审基线，不代表已经修改现有业务页面。

## 1. 结论先行

- **全平台统一字体栈**：`Inter, Noto Sans SC, PingFang SC, Microsoft YaHei, sans-serif`
- **默认正文：14px / 22px**，作为列表、表单、说明文字的基准。
- **正文 / 表格 / 导航 / 按钮最低值：13px**。12px 只留给辅助说明、时间戳、来源等元数据。
- **全平台硬下限：12px**。低于 12px 的文字禁止出现在任何业务可读界面中。
- **移动端不通过缩小字体换密度**：移动端正文仍为 14px，优先减少字段、拆分信息或允许滚动。
- **默认只使用 400 / 500 / 600 / 700 四档字重**，避免过细或过粗导致识别困难。
- **所有正文必须配合足够行高**：中文正文建议 1.55–1.65 倍，英文/数字不低于 1.4 倍。

| 角色 | 令牌 | 字号 / 行高 | 字重 | 使用场景 |

### 2.1 最小字号红线

| 允许范围 | 规则 |
| --- | --- |
| 16px | 页面标题、重要导航、关键操作 |
| 14px | 默认正文、表格、表单、消息、移动端内容 |
| 13px | 导航、按钮、紧凑表格正文、次要信息 |
| 12px | 帮助文案、时间戳、状态标签、来源、元数据 |
| **< 12px** | **禁止用于业务可读文本**；只允许用于图表坐标轴或纯装饰性标记，并需单独评审 |

## 3. 使用规则

### 3.1 层级

1. 同一页面最多出现 5 个文字层级：页面标题、分区标题、卡片标题、正文、辅助信息。
2. 不使用“字号 + 颜色 + 大量加粗”同时制造层级，优先通过字号、字重和留白表达关系。
3. 数字、金额、订单号、时间等连续数据使用 `font-variant-numeric: tabular-nums`，保证列对齐。

### 3.2 行高与宽度

- 中文正文：`line-height: 1.55–1.65`。
- 单行按钮、标签：`line-height: 1.4–1.5`，垂直居中。
- 长文案单行长度建议控制在 42–56 个中文字符；超过后换行，不通过缩小字号解决。
- 表格字段优先保证列宽和换行策略，不能用 10–11px 字体“塞下所有列”。

### 3.3 密度模式

- **舒适模式（默认）**：正文 14px，表格行高 44–48px，适用于工作台、设置、消息和风险确认。
- **紧凑模式（受控）**：正文 / 表格 13px，表格行高不低于 40px，只用于大批量数据表；辅助信息仍为 12px。
- **移动模式**：正文 14px，点击目标不低于 44px；需要提高信息量时优先折叠、分页或分步呈现。

## 4. 颜色与可读性

- 主文本使用 `#111827`，次文本使用 `#475569` 或 `#6B7280`。
- 正文与背景达到 WCAG AA 对比度（普通文字至少 4.5:1）。
- 不得仅靠颜色区分状态；状态标签同时提供文字或图标。
- 深色侧栏上的文字不得低于 12px，正文建议使用 `rgba(255,255,255,.72)` 以上对比度。

## 5. 桌面 / 移动统一基线

| 场景 | 桌面 | 移动 |
| --- | ---: | ---: |
| 页面标题 | 24 / 32 | 20 / 28 |
| 卡片标题 | 16 / 24 | 16 / 24 |
| 正文 | 14 / 22 | 14 / 22 |
| 次要说明 | 13 / 20 | 13 / 20 |
| 帮助 / 元数据 | 12 / 18 | 12 / 18 |
| 核心数字 | 28 / 34 | 24 / 30 |
| 按钮文字 | 14 / 20 | 14 / 20 |

## 6. 禁用项（反例）

- 不使用 9px / 10px / 11px 作为导航、正文、表格、表单、按钮或状态文字。
- 不用 `font-weight: 300` 承载浅色背景上的小字。
- 不通过缩放整个页面、浏览器级别缩放或 `transform: scale()` 来补救字体过小。
- 不在同一个页面中混用多套字体栈或中文字体。

## 7. 落地顺序（后续编码时执行）

1. 先替换全局字号令牌和组件基础样式。
2. 优先治理侧栏、表格、表单、状态标签、消息和移动端页面。
3. 再处理特殊页面、图表坐标轴和数据密集区。
4. 最后用固定桌面 / 移动 viewport 做视觉回归，检查“可读性优先”是否被局部样式覆盖。

## 8. 评审口径

本规范通过的最低条件：

- 正文、表格、导航和按钮无 `< 13px`；业务可读文本无 `< 12px`。
- 默认正文统一为 14px。
- 移动端正文不小于 14px。
- 页面标题、卡片标题、正文、辅助信息能一眼分层。
- 关键数字、按钮和风险状态在 1440×900 与 390×844 下都可轻松识别。
