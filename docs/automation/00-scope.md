# 商品自动化配置与执行范围

## 目标

为商品管理页新增四类商品级自动化规则配置：

1. 付款后自动发货；
2. 拍下未付款自动改价；
3. 评价后发送赠品；
4. 超时未评价求评价。

同时提供批量配置入口，并复用卡券管理的穿梭框选择卡券。

## 非目标

- 本切片不重写现有闲鱼 MTOP/IM 适配器；
- 不把规则塞入商品 `attributesJson`；
- 不绕过真实 API、鉴权、持久化或现有自动化执行器；
- 不以页面可打开或 HTTP 200 作为完成证明。

## 用户验收标准

- 商品列表可以选择一个或多个商品，进入批量配置；
- 单商品和批量配置均能读取并保存四类规则；
- 付款后自动发货与评价后赠品仅选择卡券，发货/赠品动作由卡券配置承载；
- 卡券选择弹窗支持搜索、全选当前结果、左右移动、取消和保存；
- 未付款改价与超时求评价保留必要业务参数；
- 外部调用失败、结果未知、重复事件、库存不足、权限错误、版本冲突均有明确结果；
- 固定 `1440×900` 与 `390×844` 视口生成设计稿/实现页截图并做像素差异记录。

## 证据要求

- 单元测试：校验、转换、状态机与幂等键；
- 集成测试：真实测试数据库/迁移、规则读写、批量保存与并发冲突；
- 浏览器 E2E：真实页面入口 → API → 测试数据库 → 页面结果；
- 视觉回归：商品列表、四个抽屉、卡券选择弹窗，逐页截图与 diff；
- 失败项、环境限制和未覆盖项必须显式记录。
