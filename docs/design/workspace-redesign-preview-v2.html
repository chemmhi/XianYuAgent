设计决策

先审核结构和信息层级，再把确认后的视觉落到正式 Workspace 路由。当前 HTML 只作为静态设计稿，不会改动现有业务代码。

  1. 1左侧固定 292px：上半区管理会话，下半区固定当前上下文，账号、商品、订单、能力和凭证引用始终可见。
  2. 2Agent 思考、ToolCall 和 Step 进度合并为一个默认折叠摘要；主聊天只保留自然语言，不让后台细节抢走对话焦点。
  3. 3确认卡明确风险等级、前后状态、Policy / Audit / Idempotency 引用，确认后只展示服务端 Outbox 结果。
  4. 4移动端不缩小桌面版：优先显示 Run 进度、待确认动作和上下文摘要，并用底部 Tab 维持导航。
  5. 5图标全部使用 currentColor 的 inline SVG；状态使用柔和 tinted pills，避免 emoji 和高饱和大色块。
本稿未改动：现有 React 组件、API、状态机和路由。点击“确认发布”只用于演示 Outbox 结果显隐。
