全平台字体规范

目标很简单：不再让用户盯着 9–11px 的文字工作。默认正文统一为 14px，正文 / 表格 / 导航 / 按钮不低于 13px，桌面和移动端使用同一套层级语言。

正文基线 14px 正文类最小 13px 辅助信息最小 12px 移动端不缩小正文 评审稿 v0.1

一眼能执行的规则

先解决“累眼”，再谈信息密度。

默认正文 14px列表、表单、消息、表格内容都以此为起点。
正文类最小 13px正文、表格、导航、按钮不低于 13px。
行高 1.55–1.65中文不挤成一团，长文案优先换行。
拒绝 9–11px 业务字需要更紧凑时，优先删字段、折叠或分页。

移动端执行口径

  • 正文、按钮、消息内容统一 14px。
  • 页面标题 20px，卡片标题 16px。
  • 辅助信息可用 12–13px，但不得低于 12px。
  • 密度问题用折叠、分页、分组解决。

建议评审结论

如果这套基线通过，下一步再进入组件级改造。

通过条件 01业务可读文本无 12px 以下字号。
通过条件 02默认正文统一 14px，移动端同样成立。
通过条件 03标题、正文、辅助信息能快速区分。
通过条件 041440×900 与 390×844 均可轻松识别。
