# 新用户空白页一致性验收（2026-10-25）

功能实现：仪表盘、Workspace、在线聊天、商品、卡券、订单、Agent 动态，以及设置的自动回复 Agent / OpenAI API 分类，使用同一账号缺失状态。白色内容区填满可用高度，标题、说明和主按钮整体双向居中；加载和错误状态分别显示等待或重新加载。账号管理保留指标和工具栏，首次使用显示“尚未添加闲鱼账号”和添加按钮，有账号但筛选无结果时仍显示筛选提示。

模块拆分：`shared/ui/PageState.tsx` 和 `page-state.css` 负责通用布局；`app/AccountContextState.tsx` 负责账号加载、失败和选择账号的引导；各业务页面只接入状态组件。按钮复用现有 `Button`。设置的邀请码分类仍独立于闲鱼账号上下文。

## 真实浏览器验收

在 Codex 内置浏览器打开 `http://127.0.0.1:15173/`，通过真实登录表单登录本地专用测试用户。后端为 `http://127.0.0.1:18880`，使用既有 `apps/api/scripts/invite-registration/test-support.mjs` 的 PostgreSQL fixture、新建独立数据库、有效邀请用户且没有闲鱼账号，未拦截业务 API 或伪造 DOM。

检查路径：`/dashboard`、`/workspace`、`/accounts`、`/messages`、`/products`、`/coupons`、`/orders`、`/agent-dynamics`、`/settings`。设置中分别点击自动回复 Agent 与 OpenAI API。

- 修复前在 1280×720 下，仪表盘白块高 300px，商品约 89px，设置 Agent 提示约 106px；另有无背景、无按钮、左对齐和不同提示。
- 修复后在相同 1280×720 下，七个业务入口和设置内容区均为 top=22、bottom=698、height=676px。提示组水平误差为 0，垂直误差约 0.008px。
- 1920×948 下，相同区域均为 top=22、bottom=926、height=904px；设置两个分类等高。按钮均为 104×32px、蓝色背景、白色文字、8px 圆角。
- 逐个点击上述八个入口的“前往账号管理”，均通过应用路由进入 `/accounts`。账号页中间的“添加闲鱼账号”按钮可打开真实账号登录弹窗，随后关闭。
- 390×844 下检查八个入口，提示组双向居中、主按钮位于视口内、文档没有横向溢出。普通页面白块底部统一为828px；设置白块底部746px，为既有底部导航保留空间。页面原有顶部导航是否显示不同，因此窄屏白块按各自剩余空间填充。测试后恢复默认视口。

桌面尺寸与实际文本见 `desktop-metrics.json`、`desktop-1280-metrics.json`；最终窄屏结果见 `mobile-metrics.json`。截图为 `dashboard-after.png`、`settings-after.png`、`settings-mobile-after.png`。
